# ggsegCIT168: CIT168 Subcortical Atlas for the 'ggsegverse' Ecosystem

CIT168 probabilistic subcortical atlas (Pauli et al. 2018) for the
'ggseg' ecosystem. Provides a 'ggseg_atlas' object with 2D polygon
geometry and 3D mesh data, covering the striatum, pallidum and the small
midbrain and diencephalic nuclei, for use with 'ggseg' and 'ggseg3d'.
